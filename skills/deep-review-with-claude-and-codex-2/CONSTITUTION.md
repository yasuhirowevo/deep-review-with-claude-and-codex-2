# deep-review-with-claude-and-codex-2 Constitution

## 目的

固定した同一入力を外部Claude Code CLIと外部Codex CLIが独立にレビューし、見落としを広く探索する。
そのうえで、指摘の重要度と「今回のPRでどう扱うか」を分離し、人間が対応判断を誤らない
読みやすいレポートとして提示する。

## 不変条件

- BASE / HEAD、safe diff、HEAD snapshot、BASE guidance、toolingを固定し、入力と出力をattestationで検証する。
- ClaudeとCodexには同じ固定入力と品質契約を渡し、互いの結果、PRコメント、既存findingを渡さない。
- 対象worktreeを変更せず、レビュー成果物以外の副作用を起こさない。
- 片側失敗、入力不整合、未収束をfinding 0件や完了として扱わない。
- 重要度は、現実的な成立条件と影響から判断する。重要度だけから、このPRでの対応要否を自動決定しない。
- 変更範囲外を含む妥当な候補を隠さない。一方で、このPRの目的に不要な問題を当PRの対応候補へ自動的に格上げしない。
- 過去の対応済み・受容済み判断は、新しい根拠がない限り同じ指摘として再提起しない。
- 人向け要約と監査証跡の両方を保持し、同じ正典artifactから機械的に照合できるようにする。

## 非対象

- 一つのPRで隣接する全問題を完全に解消すること。
- 重要度をコード変更の許可、マージ禁止、または対応必須の宣言として扱うこと。
- レビュー結果だけを根拠に対象worktreeを修正すること。
- 法令・規制、セキュリティ、プライバシー、品質、製品仕様などの専門領域に関する正式判断を、レビューAIだけで確定すること。
- 変更範囲外の妥当なセキュリティ候補を無かったことにすること。

CONSTITUTION.mdの変更・削除は、それを対象とするユーザーの明示指示の範囲でのみ行える。通常の修正・改善依頼はその許可を含まない。
